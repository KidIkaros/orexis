# M6 — Evolution

**Status:** automated gate green (2026-10-26); manual `/evolve` inspection remains. Decision 008 resolved by ADR-0015.

## Scope

A tiered, git-backed, sealed, signed evolution corridor: mutation proposals,
quarantine, the validation ladder, apply/rollback, and a 100-cycle gate.

## Tiers (ADR-0015)

| Tier | Default | Candidate | Auto-apply | Human |
|---|---|---|---|---|
| `off` | **yes** | none | no | — |
| `skills` | opt-in | quarantine | after ladder | no |
| `quarantine` | opt-in | quarantine | never | yes |
| `core` | opt-in | quarantine | never | yes + signed |

Every candidate is quarantined first. Fresh installs are `off`.

## Mutation surface

Data only: prompt/strategy fragments, gene parameters, skill content,
recall/reflection policy. No code, scripts, permissions, sandbox,
provider/model, tools, codec/protocol, secrets, telemetry, safety floor, or
identity policy. The sealed set is hashed and recorded.

## Validation ladder

1. Strict schema and size caps.
2. Seal unchanged.
3. Static safety: no new capability/network/shell/secrets/executable content.
4. Deterministic tests.
5. Behavioral evaluation: paired baseline/candidate, noise band.
6. 24h quarantine soak; human review for `quarantine`/`core`.
7. Signed git apply with ledger entry.
8. Monitor and rollback.

## Cadence

Session boundaries only. One proposal per session and per day. One `skills`
apply per day; `core` on human approval. The gate runs 100 accelerated cycles.

## Rollback

Automatic on permission bypass, sandbox escape, secret exposure, refusal
removal, chain/signature failure, unrecoverable state, or failed verify.
Automatic for `skills` on regression; human for `core`. Git revert + ledger
`Revert` event.

## Architecture

- `orexis-core::evolution`: `Tier`, `Mutation`, `Candidate`, `Seal`,
  `LedgerEntry`, `ValidationReport`.
- `orexis-ports`: `EvolutionStore`, `MutationSource`, `Validator`, `Signer`.
- `orexis-usecases::evolution`: pure ladder, apply/rollback decisions.
- `orexis-adapters-evolution-git`: git repo, JSONL ledger, quarantine,
  Ed25519 signing.
- `orexis-composition`: wiring; no adapter construction elsewhere.

## Research track (not gate)

M6-R01 audits the opt-in Ed25519 + Falcon-1024 experiment crate. It does not
block M6-05 and does not change the default Ed25519 signer.

## Does not ship

- Code mutation or executable content from quarantine.
- Permission/provider/model mutation.
- Team evolution (M8).
- Automatic `core` changes.

## Gate

- [x] 100 accelerated cycles; zero unrecoverable states.
- [x] Sealed set unchanged in every applied candidate.
- [x] Quarantine never auto-applies executable content.
- [x] Ledger chain and signatures verify; tamper blocks apply.
- [x] Rollback fixture restores the last signed good state.
- [x] `scripts/m6-gate.sh` green (automated).
