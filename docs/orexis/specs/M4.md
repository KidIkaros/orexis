# M4 — Recovery and supply-chain hardening

**Status:** in progress (2026-10-26).

## Scope

- **Crash recovery:** a SIGKILL mid-turn must leave a replayable session; the
  next attach marks the unfinished turn as recovered; checkpoints and undo
  survive.
- **Audit trail:** privileged actions (approvals, shell/write/edit calls,
  checkpoints, verify, errors) are durable and exportable.
- **Skill trust tiers and quarantine:** manifests, hashes, tiers, and a
  quarantine that prevents loading a tampered or untrusted skill.
- **Gate:** `scripts/m4-gate.sh`.

## Does not ship

- Skill execution or a marketplace.
- Encryption at rest.
- Multi-user audit.

## Gate

- [ ] `kill -9` mid-turn leaves a session that replays and recovers.
- [ ] Audit export contains approval decisions and privileged tool calls.
- [x] A tampered skill is quarantined and cannot be loaded.
- [ ] `scripts/m4-gate.sh` green.
