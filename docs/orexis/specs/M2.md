# M2 — Desktop oversight workspace

**Status:** specified 2026-10-26. Ticket 006 resolved (ADR-0008); M2-01 in progress (bridge/state complete, Leptos UI wasm check passes, Tauri shell build pending system libraries).

## Goal

A native desktop workspace for oversight: steer a session, approve and review
changes, and inspect the fleet, board, artifacts, and entity — over the same
local daemon as the TUI.

## Scope

**Ships in M2**

- Tauri + Leptos single window; no web surface, no HTTP server for UI clients.
- Six panels: chat/streaming, fleet, approvals, diff viewer, artifacts, file browser.
- Settings modal: model/provider, permissions, privacy ("what leaves this machine").
- Shared daemon attach over the Unix socket through the Tauri Rust side.
- Keyboard-first interaction; ARIA labels; reduced motion; high contrast.
- Two formative evaluation cycles and the usability spec below.

**Does not ship in M2**

- Entity, drives, memory (M5).
- Evolution (M6).
- MCP/ACP/UTCP/A2A (M7).
- Team mode (M8).
- Multi-window, mobile, web.

## Layout contract

Three zones, from `docs/orexis/prototypes/desktop-layout.md`:

| Tier | Panels | Where |
|---|---|---|
| Primary | Chat / streaming | Center |
| Secondary | Approvals, Diff, Preview | Right panel, contextual |
| Tertiary | Sessions, Board, Fleet, Artifacts, Files | Left rail |
| Modal | Settings, palette | Overlay |

Focus is composer-first; `⌘1`…`⌘6` focus panels; `⌘⇧A` approvals; `Esc` returns
to the composer. Approvals never steal focus; a badge announces them.

## Usability acceptance

From `docs/orexis/prototypes/desktop-usability.md`:

| Attribute | Instrument | Worst acceptable | Planned target |
|---|---|---|---|
| Core task completion (steer) | Task script + observation | 4/5 | 5/5 |
| Time to first reviewed diff | Screen/keystroke log | ≤ 5 min | ≤ 3 min |
| Approval comprehension | Think-aloud + question | 4/5 | 5/5 |
| Keyboard-only completion | Input log | 5/5 | 5/5 |
| Error recovery (failed verify) | Task script | 4/5 | 5/5 |
| Panel findability | Task timing, < 10 s each | 4/5 | 5/5 |
| Satisfaction (1–7) | Post-task questionnaire | median 5 | median 6 |

## Evaluation

- **Cycle 1:** wireframes, analytic pass + 3 developers, think-aloud on steer/recover/inspect.
- **Cycle 2:** clickable Tauri shell, 5 developers, metrics against the table.
- Findings feed redesign; the M2 gate records any miss with a decision.
