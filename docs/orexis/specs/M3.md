# M3 — Coding surface and safety floor

**Goal:** Orexis can read, edit, search, run tests, use git, review diffs, and refuse unsafe actions — on a real repository.

**Status:** implemented 2026-10-26. `scripts/m3-gate.sh` is green; live-provider runs remain manual.

## Scope

**Ships in M3**

- Tools: `read_file`, `write_file`, `edit_file` (exact, then fuzzy), `list_dir`, `search`, `shell`, `git_status`/`git_diff`, `verify`.
- Path sandbox: every path resolves inside the project root; symlink escapes rejected.
- Permission ruleset: `deny > ask > allow`; plan mode is read-only; shell and writes are approval-required by default.
- Sandboxed shell: project-root cwd, timeout, per-stream output caps, process group, no orphans.
- Turn-level checkpoints: shadow-git snapshots, `/undo`, diff review before commit.
- Verify-on-stop: a configured test/build command runs before the agent claims done.
- LSP diagnostics: post-edit errors surfaced to the model.
- The M1 real-task gate: read, edit, test, and diff a real repository.

**Does not ship in M3**

- Desktop (M2, now after M3).
- Entity, drives, memory (M5).
- Evolution (M6).
- MCP/ACP/UTCP/A2A (M7).
- Team mode (M8).

## Tools

| Tool | Args | Behaviour |
|---|---|---|
| `read_file` | `path`, optional `max_bytes` | Returns UTF-8 content, truncated at 64 KB with a marker |
| `write_file` | `path`, `content` | Creates parent dirs inside the root; returns bytes written |
| `edit_file` | `path`, `old`, `new` | Exact unique-substring replacement; 0 or >1 matches is an error |
| `list_dir` | `path` | Sorted entries, `dir/` or `file size`, capped |
| `search` | `query`, optional `path` | Recursive substring search, skips `.git`/`target`/`node_modules`, capped at 100 hits |
| `shell` | `command`, optional `timeout_secs` | Sandboxed shell, 120 s default, 64 KB per stream |
| `git_status` / `git_diff` | optional `path` | Read-only git queries |
| `verify` | optional `command` | Runs the configured test/build command |

## Safety floor

- **Path sandbox:** resolve relative to the root, reject `..` escapes and symlink escapes.
- **Permission ruleset:** each tool has a latitude (`auto`, `approval_required`, `forbidden`); plan mode forbids writes and shell.
- **Shell sandbox:** cwd at the root, process group, timeout, output caps, no inherited secrets.
- **Checkpoints:** a shadow-git snapshot per turn; `/undo` restores files; diffs are shown before commit.
- **Verify-on-stop:** `Done` is refused until the verify command passes, unless the user explicitly skips.

## Acceptance gate

- [x] A real repository task: read a file, edit it, run tests, review the diff.
- [x] Path escapes (relative, absolute, symlink) are rejected.
- [x] Plan mode cannot write or run shell.
- [x] Approval-required tools block until approved.
- [x] Shell timeout kills the process group; output caps hold.
- [x] `/undo` restores the pre-turn state.
- [x] Verify-on-stop blocks a false `Done`.
- [x] LSP diagnostics reach the model after an edit.
- [x] Adversarial suite: traversal, symlink, command injection, output bombs.
