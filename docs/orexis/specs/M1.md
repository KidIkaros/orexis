# M1 — A working harness

**Goal:** a single-agent harness that runs on three providers, persists sessions, renders in a TUI, and replays byte-identically.

**Status:** implemented 2026-10-26. Automated gate green via `scripts/m1-gate.sh`; the live-provider and real-task checks remain manual.

## Scope

**Ships in M1**

- SQLite session store implementing ADR-0001: append, read, fork, generations, lazy migration, request hashes.
- Provider catalog implementing ADR-0002: profile schema, vendored snapshot, precedence, keyring/env secrets.
- Three live providers: OpenAI-compatible, Anthropic, llama.cpp.
- Four codecs and automatic selection (ADR-0003): `native`, `xml-manual`, `json`, `lenient`.
- Context assembly and threshold compaction.
- ratatui TUI implementing ADR-0004: four regions, keymap, eleven states, virtualized transcript.
- Daemon + attach over Unix-socket NDJSON: session registry, one local generation at a time, replay on attach.
- Import-lint enforcing the Dependency Rule and the `tokio` ban; generated seam graph.
- End-to-end replay assertion.

**Does not ship in M1**

- Permissions, sandbox, approvals (M3).
- Desktop (M2).
- Entity, drives, memory (M5).
- Evolution (M6).
- MCP/ACP/UTCP/A2A (M7).
- Team mode (M8).

## Behaviour

**Turn loop.** Derive messages from the event log → assemble the request → select the codec from model capability → call the provider (streaming) → parse actions → execute tools → append events → repeat until `Done`, `max_steps`, or budget.

**Streaming.** Provider deltas go to the `EventSink` for live rendering; they are not persisted. `ModelResponse` is persisted whole.

**Context.** System prompt + tool docs + project context files + history; threshold compaction at a fixed buffer below the model's context, verbatim tail, incremental summary, `Compaction` event.

**TUI.** ADR-0004: status, transcript, composer, keyhints; overlays for fleet/board/self (fleet and board read-only until M8); eleven states; composer-first focus.

**Daemon.** `orexis serve` binds `$XDG_RUNTIME_DIR/orexis-<uid>.sock`; `ClientMsg`/`ServerMsg` NDJSON; one `Semaphore(1)` per local provider; attach replays stored events by `seq`, then follows live; detach leaves the session running.

## Risks

| Risk | Mitigation |
|---|---|
| Provider dialects diverge more than expected | Mock conformance per dialect; native adapters only where the wire differs |
| SQLite migrations break replay | Migration fixtures; `verify_replay` in CI |
| TUI work expands past the contract | ADR-0004 is the boundary; snapshot tests, no new panes |
| Daemon concurrency bugs | One generation per local provider; attach replay by `seq`; kill -9 test |
| M1 becomes M2 | The non-goals list is explicit; new work goes to a ticket, not into M1 |
